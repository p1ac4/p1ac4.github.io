Compatibility matrix · v0.1.0

一条支持路径，完成端到端验证。

APIdapter v0.1.0 是聚焦 Raycast 到 DeepSeek 的兼容版本。本页明确区分已验证行为与未来产品方向。

支持的产品路径

层级v0.1.0 支持项边界
AI clientRaycast Custom ProviderRaycast 必须发送 model 和 tools。
本机 endpointPOST /chat/completions 的 OpenAI Chat Completions只允许 loopback listener。
Modeldeepseek-v4-flash其他 model ID 会 fail closed。
Provider官方 DeepSeek API固定为 https://api.deepseek.com/chat/completions。
操作系统macOS arm64 与 amd64目前不发布 Linux 或 Windows binary。

协议行为

能力状态APIdapter 的处理
Streaming text支持立即转发并 flush 每个 SSE event。
Streaming reasoning支持把 reasoning_content 映射到 Raycast 显示的 reasoning 字段。
Non-stream response支持在不使用 SSE 时转换最终 reasoning 字段。
单次 tool call支持规范化 request fields 与 response content。
Multi-turn tool calls支持跨 tool turns 回放受限的 provider-required reasoning state。
Cancellation支持把 client cancellation 传递给 upstream request。
自定义端口支持使用 --listen 或 JSON listen 字段。
Prompt 与 key 持久化默认关闭不记录或持久化内容与 credential。
真实 completion evidence 该 release path 于 2026 年 8 月 9 日完成真实测试：Raycast 连续调用两次 Calculator tool，随后由 model 生成最终答案。

暂不支持

其他 client

v0.1.0 不包含 VS Code 与 Warp。

其他 API protocol

不包含 Anthropic API 与 OpenAI Responses API。

其他 runtime feature

不包含 Vision、multi-provider routing、UI 与自动后台安装。

兼容范围以具体 release 为准。
