快速配置

四步完成，然后打开 Raycast。

  1. 添加 executable bit 并启动。 
    chmod +x apidapter_v0.1.0_darwin_arm64
./apidapter_v0.1.0_darwin_arm64
  2. 检查本机 health endpoint。 
    curl http://127.0.0.1:48765/healthz
  3. 配置 Raycast Custom Provider。

    使用仓库中的 provider 示例，把 base URL 设为 http://127.0.0.1:48765，并将 placeholder 替换为你自己的 DeepSeek API key。

  4. 在 Raycast 中选择 tools。

    选择 DeepSeek V4 Flash，然后用 @ 添加所需 AI Extension。APIdapter 负责兼容 Raycast 已发送的 tools，不会凭空增加 tools。
