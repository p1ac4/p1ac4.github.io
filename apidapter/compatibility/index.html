Compatibility matrix · v0.1.0

One supported path, tested end to end.

APIdapter v0.1.0 is a focused Raycast-to-DeepSeek compatibility release. This page separates verified behavior from future product direction.

Supported product path

LayerSupported in v0.1.0Boundary
AI clientRaycast Custom ProviderRaycast must send the model and tools.
Local endpointOpenAI Chat Completions at POST /chat/completionsLoopback listener only.
Modeldeepseek-v4-flashOther model IDs fail closed.
ProviderOfficial DeepSeek APIFixed to https://api.deepseek.com/chat/completions.
Operating systemmacOS arm64 and amd64Release binaries are not currently published for Linux or Windows.

Protocol behavior

CapabilityStatusWhat APIdapter does
Streaming textSupportedForwards SSE events immediately and flushes each event.
Streaming reasoningSupportedMaps reasoning_content to the reasoning field Raycast displays.
Non-stream responseSupportedTranslates the final reasoning field without SSE.
Single tool callSupportedNormalizes request fields and response content.
Multi-turn tool callsSupportedReplays bounded provider-required reasoning state across tool turns.
CancellationSupportedPropagates client cancellation to the upstream request.
Custom portSupportedUse --listen or the JSON listen field.
Prompt and key persistenceDisabled by defaultContent and credentials are not logged or persisted.
Live completion evidence The release path was tested on August 9, 2026 with two sequential Raycast Calculator tool calls followed by a final model answer.

Not supported yet

Other clients

VS Code and Warp are not included in v0.1.0.

Other API protocols

Anthropic API and OpenAI Responses API are not included.

Other runtime features

Vision, multi-provider routing, UI, and automatic background installation are not included.

Compatibility is release-specific.
