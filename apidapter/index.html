Quick setup

Four steps. Then open Raycast.

  1. Make the binary executable and start it. 
    chmod +x apidapter_v0.1.0_darwin_arm64
./apidapter_v0.1.0_darwin_arm64
  2. Verify the local health endpoint. 
    curl http://127.0.0.1:48765/healthz
  3. Configure Raycast Custom Provider.

    Use the repository's provider example, set its base URL to http://127.0.0.1:48765, and replace the placeholder with your own DeepSeek API key.

  4. Select tools in Raycast.

    Choose DeepSeek V4 Flash, then add the required AI Extension with @. APIdapter makes exposed tools compatible; it does not invent tools Raycast did not send.
